# QGroundControl

QGroundControl（QGC）地面站软件，用于连接 SITL / 真机、监控飞行状态、下发指令。

## 下载

AppImage 体积约 180 MB，已加入顶层 `.gitignore`（不会上传仓库）。请下载后放到本目录：

- **文件**：`QGroundControl-x86_64.AppImage`
- **网盘**：<https://pan.baidu.com/s/148r9UuOoxBYkWqvJqKU8bA>　**提取码**：`8888`
- **官方下载（备选）**：<https://qgroundcontrol.com/downloads/>

## 运行

```bash
chmod +x QGroundControl-x86_64.AppImage
./QGroundControl-x86_64.AppImage
```
